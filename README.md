# T-Rex Upgraded

T-Rex Upgraded is a 2D endless runner game written in Rust using the Bevy game engine.

## Features

- Main menu
- Player setup with name input
- Jumping player character
- Random obstacle spawning
- Collision detection
- Health system
- Score system
- Local scoreboard
- Dynamic difficulty
- Music and settings menu

## Controls

- Space - Jump
- Escape - Back to menu
- Mouse - Menu interaction

## Running from source

```bash
cargo run
